# 怎么加一间屋

2026-11-17 · 曦宝。做之前先读 `concepts/room-vignettes/房间小剧场做法.md`（规矩和步骤）和 `concepts/hall-vignette-v1/界面与引导规范.md`（界面）。这份只讲文件怎么写。

## 文件怎么分

| 文件 | 内容 | 谁改 |
|---|---|---|
| `../indoor.js` | 公共部分：怎么看、怎么引导、怎么演、界面 | 只有曦宝。要新功能就提给曦宝 |
| `index.js` | 哪些房间用固定机位（一行名单） | 加自己的房间时加一个名字 |
| `<房间编号>.js` | 这间屋的站位、能坐的椅子、每一拍的内容 | 这间屋的负责人 |
| `../rooms.js` | 房间的范围和门（原有） | 一般不用改 |

房间编号用 `../rooms.js` 里的名字：`tingzi` 亭子间、`lounge` 二楼起居间、`marital` 婚房、`childroom` 孩子房、`terrace` 晒台，等等。

**一间屋只有一个负责人**，写在文件第一行。别人的房间文件不要改。

## 步骤

1. 新建 `vignettes/<房间编号>.js`，照下面的样子写。
2. 在 `vignettes/index.js` 的名单里加上这个编号。
3. 打开试样页，进这间屋试。没列进名单的房间仍是原来的走动方式，所以可以一间一间加。

现成的例子：`courtyard.js`（最简单，只有站位、引导和一把能坐的椅子）、`hall.js`（完整的一出戏）。

## 一间屋的文件

```js
// 亭子间 · 负责人：云宝
export default {
  // 站的地方和默认看向哪里。世界坐标，米，北是 -z；人眼高度 = 这间屋地面高度 + 1.45
  spot: { pos: [x, y, z], look: [x, y, z] },

  // 可选：通到哪间屋（那间屋也要在名单里）。画面底部会出一行字
  next: { to: 'mezzanine', label: '回平台' },

  // 可选：门上常亮的去处（没有戏在演、也没有别的引导时显示）。at 是门洞上的一个点
  doors: [{ label: '厨房', at: [x, y, z], to: 'kitchen' }],

  // 可选：名字里带这些字的物件可以坐（椅面高度和朝向自动量，靠背在哪边就背对哪边）
  sit: /藤椅|木椅/,

  // 建议写：点到物件时显示的名字。模型里的名字是给做的人看的；带英文、编号、“新增道具”之类的不会显示，其余原样显示
  names: { '模型里的名字': '给玩家看的名字' },

  // 可选：没有戏在演的时候，站定后的引导。返回 null 就不引导
  cue: (h, { first }) => ({ label: '看看窗外', sub: first ? '窗台上晒着被头。' : null, delay: 3000, at: [x, y, z], run: () => { /* 点了之后做什么 */ } }),

  // 可选：这间屋的戏
  story: {
    setup(h, d) { },      // 进屋子时就摆好（不等走进这间屋，免得从隔壁看过来穿帮）：藏起来的东西、要加进场景的东西。d 是这间屋自己的记事本
    dispose(h, d) { },    // 离开游戏时还原 setup 做的事
    beats: [ /* 一拍一项，见下 */ ],
    outro: { after: 5000, sub: '……' },   // 最后一拍做完，等多久、出哪句字幕，然后屋子交还给玩家
    // outro 里还可以写 back: true：演完退回进门的站位
    // 最后一次点击后需要接一段分镜时，可写 outro.act(h, d, done)。演完调用 done()，再显示下一步提示。
    // outro 里还可以写 exit：演完后画面下方出去处。exit: { label: '回客堂', to: 'hall' }，或写成一组并排出几个

    // 可选：任务单（客堂用来放阿婆字条上的三件事；别的房间一般不需要）
    tasksTitle: '', tasksAfter: '哪一拍做完后出现', tasks: ['……'],
  },
};
```

## 一拍

```js
{ id: 'quilt',                       // 这一拍的名字，本文件内不重复
  label: '拍被头',                    // 光点旁边的字，两到五个字
  sub: '窗台上晒着被头。',              // 字幕。不带人称，说眼前的东西；不用阿婆的口吻
  target: '晒台_棉被',                 // 目标物件的名字；或者 (h, d) => d.某样自己加的东西
  markAt: [x, y, z],                  // 可选：目标被挡住时，光点另指一个点
  pose: { pos: [x, y, z], look: [x, y, z] },   // 可选：点了之后镜头走到哪、看哪。不写就原地演

  // 动作三选一：
  act: (h, d, done) => { /* 物件自己动 */ done(); },                        // 做完必须调用 done()
  read: { img: 图片地址, alt: '图上写了什么', hint: '下面一行小字' },          // 看一张纸
  sit: { at: [x, z], facing: [x, 0, z], seatY: .55, eye: 1.25, lean: false },   // 坐下（没有靠背的凳子要这样写明朝向）

  card: { hu: '被头', zh: '被子', note: '一句介绍。' },   // 词卡；不写就没有词卡
  audio: 'W7',                        // 录音编号，文件放 ../audio/W7.m4a
  task: 1,                            // 可选：对应任务单第几条
  taskOf: 0,                          // 可选：这一拍属于任务单第几条，但做完还不划掉（一件事分两拍时用）
  also: ['茶杯_1'],                    // 可选：除了目标，点这些物件也算
  enter: (h, d) => { },               // 可选：这一拍一开始就做的事
  then: (h, d, done) => { done(); },  // 可选：只用于 sit，坐定以后接着演的一小段
  collect: ['seven', 6],              // 可选：点亮收集册里哪一套的第几样（从 0 数）；一次亮几样写成 [['seven', 2], ['seven', 3]]
}
```

每拍先出字幕，镜头对准 `markAt` 或目标物件，停稳后再亮光点。原地看不到物件时，可用 `guideFrom: [x, y, z]` 指定亮光点前的观察位置。点击光点后执行 `pose` 和动作，需要直接叠化到近景时可用 `pose.fade: true`。

## 动作里能用的工具 `h`

| 写法 | 做什么 |
|---|---|
| `h.find('名字')` | 按名字找屋里的物件。显示隐藏直接改它的 `.visible` |
| `h.wait(毫秒, 函数)` | 等一会儿再做。不要自己用 `setTimeout`，否则中途离开房间会出错 |
| `h.drop(物件, done)` | 物件从上面落下、顿两下，约 1.2 秒 |
| `h.tv('hallTv', true)` | 开关电视。现有 `hallTv` 客堂、`maritalTv` 婚房 |
| `h.tween(毫秒, k => { }, done)` | 一段动作：这段时间里每帧调用一次，k 从 0 走到 1（开门、倒水、物件沿一条线移动都用它）|
| `h.gaze([x, y, z], { go: 900, hold: 2000 }, done)` | 镜头自己看向一个点，停一会儿，再把视线交还（坐着也能用）|
| `h.sound('radio', { loop: true, volume: .5 })` | 播 `../audio/radio.m4a`；文件还没有就安静。返回的函数用来停掉 |
| `h.loop(now => { })` | 一直持续的小动静（热气之类），返回的函数用来停掉 |
| `h.say('字幕', '说话的人', 毫秒)` | 出一句字幕 |
| `h.go('房间编号')` | 叠化到另一间屋 |
| `h.started('hall')` / `h.finished('hall')` | 别的房间的戏开始了没有、演完了没有 |
| `h.THREE`、`h.scene` | 自己往场景里加东西时用（记得在 `dispose` 里拿掉） |

移门、倒水的现成例子在 `hall-tea.js`。需要别的而这里没有，告诉曦宝，加到公共部分里，大家都能用。不要在房间文件里自己操作镜头或界面。

## 不要做的事

- 不改 `../indoor.js`。
- 不改别人的房间文件。
- 不用阿婆的口吻写字幕（只有客堂念字条时用）。
- 不做“1/3”换站位；一间屋一个站的地方。
- 一段戏演完不暗场、不弹总结、不安排谁回来。
